# Cobaya-based mock likelihoods for joint analyses of CMB, Type Ia Supernova, and BAO datasets.
## Paper:
* Raghunathan S., LSST-DESC 2026; arXiv:[2603.09973](https://arxiv.org/abs/2603.09973). 

## Likelihoods
* ### Naming convention: Dataset1+Dataset2+....-cosmology_model
  * #### spt3g-TTEETEPP-mnulcdm: SPT-3G TT/EE/TE/PP chains for $\sum_{\nu} \Lambda {\rm CDM}$ cosmology.
  * #### advanced_so_baseline-TTEETEPP+desidr3bao_lowz_mock+desidr3bao_highz_mock-mnulcdm: Advanced-SO (Baseline configurations) TT/EE/TE/PP combined with DESI DR3 low- and high-z BAO chains for $\sum_{\nu} \Lambda {\rm CDM}$ cosmology.
  * #### advanced_so_baseline-TTEETEPP+desidr3bao_lowz_mock+desidr3bao_highz_mock-mnuomklcdm: Advanced-SO (Baseline configurations) TT/EE/TE/PP combined with DESI DR3 low- and high-z BAO chains for $\sum_{\nu} + \Omega_{k} + \Lambda {\rm CDM}$ cosmology.
